# Vendored ACP runtime

This directory is a vendored copy of `packages/acp-runtime/src/` from
[open-managed-agents](https://github.com/open-ma/open-managed-agents).

It is owned by `@clash/local-api` until the upstream runtime is published.
Change the upstream package and re-vendor it here; do not maintain a second
runtime implementation in another Clash workspace package.
