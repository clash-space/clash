# Functional benchmark input Environment

`base-workspace-v1` is generated by
`benchmarks/generate-environment-workspaces.ts`. It is an exact portable Clash
Workspace bundle, not a SQLite snapshot or an evaluator-specific fixture.
Its `project.bin` is a deterministic, non-conflicting current-frontier
`loro-shallow-snapshot` carrying the Project authority markers accepted by the
real Host. Regenerate it with the script; do not hand-edit the manifest or pin
an evaluator-only format.
