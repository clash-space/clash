# Anny MPFB2 Director Stage bodies

These GLB files are generated from the MPFB2 topology and shape data shipped
with [NAVER's Anny](https://github.com/naver/anny) at commit
`e53d4b8a6ce4e8b5f257c4cee92cffcfb3d3efb9` (Anny 0.5).

- Anny source code: Apache License 2.0
- Anny `data/mpfb2` source assets: CC0 1.0 Universal
- Output topology: `default-noeyes-notongue`
- Rig: Anny's bundled Mixamo-compatible 52-bone rig
- Material: Clash clean mannequin material; no source textures are embedded

The nine files use the same topology and skeleton with distinct Anny phenotype
parameters. They are generated meshes, not scaled copies of one body.
